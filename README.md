# CMSAC Notes

Personal notes and potential basketball applications from the 2026 Carnegie Mellon Sports Analytics Conference, compiled by Adrian Kong.

View the site: https://realmabg.github.io/cmsac-notes/

The site uses plain HTML with collapsible articles and sections. `index.html` contains the conference notes; `ucsd.html` contains UCSD implementation ideas. Edit the corresponding file to update each page. GitHub Pages publishes the root of the `main` branch; `.nojekyll` keeps it as plain HTML.

These are personal notes and may contain errors or misinterpretations. Consult the project authors before referencing their research.
